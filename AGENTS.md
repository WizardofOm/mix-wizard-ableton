# Mix Wizard for Ableton: agent guide

This repository is a set of mixing and mastering skills for Ableton Live. Each skill is a folder under `skills/` with a `SKILL.md` in the open Agent Skills format (a `name`, a `description` saying when to use it, and instructions).

If your tool loads skills natively, install the folders from `skills/` and ignore this file. If it does not, use this file as the index: when a request matches a row below, read that skill's `SKILL.md` in full and follow it.

## Skill index

| When the user... | Read |
| --- | --- |
| wants a blunt expert diagnosis, or asks for engineer mode | `skills/perception-first-engineer/SKILL.md` |
| says the mix is muddy, dull, or boxy, or asks how to EQ | `skills/clean-eq/SKILL.md` |
| is starting a mix, or asks how to balance levels or set faders | `skills/level-first-mix/SKILL.md` |
| wants something more forward or further back, or has an uneven vocal take | `skills/depth-with-limiters/SKILL.md` |
| has a loose, boomy, or thin low end, or asks where to high-pass | `skills/low-end-handoff/SKILL.md` |
| can't hear the vocal clearly against guitars, keys, or synths | `skills/vocal-guitar-pocket/SKILL.md` |
| asks how compression, ratio, threshold, or makeup gain work | `skills/compression-math/SKILL.md` |
| says the mix is thin or lacks glue, or asks about parallel compression | `skills/parallel-bus/SKILL.md` |
| wants to compare the mix to a commercial track, or asks if it is finished | `skills/reference-check/SKILL.md` |
| is finishing a track and wants it louder, shinier, or release-ready | `skills/master-polish/SKILL.md` |
| is about to record vocals, or asks about microphones at home | `skills/vocal-tracking/SKILL.md` |
| has a loop or unfinished dance track and needs structure or energy flow | `skills/dance-arrangement-architect/SKILL.md` |

## Rules for every skill

1. You are assisting a producer. The music is theirs; you handle technique.
2. Read the session before changing it. Confirm before anything destructive, and never change the master without asking.
3. One change at a time, so each can be compared on and off.
4. Stock Ableton devices first. Mention third-party plugins only as options.
5. All frequencies and amounts are starting points. Ask the user to listen after each change.
6. If no Ableton tools are connected, give the same settings as clear steps for the user to apply by hand.
